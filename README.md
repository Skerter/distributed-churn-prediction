# Distributed Churn Prediction

Проект демонстрирует построение **масштабируемого ML‑пайплайна для
прогнозирования оттока клиентов (Customer Churn)**, реализованного в
трёх различных режимах выполнения:

-   Локальная версия (single‑machine pipeline)
-   Распределённая версия на **Dask (локальный кластер)**
-   Распределённая версия на **Dask + Kubernetes**

Главная цель проекта --- показать, как один и тот же ML‑pipeline можно
масштабировать от локального прототипа до распределённой инфраструктуры.

# Обзор проекта

**Customer Churn Prediction** --- классическая задача машинного
обучения, широко используемая в телеком‑компаниях, SaaS‑сервисах, банках
и других подписочных сервисах.

Задача заключается в прогнозировании вероятности того, что клиент
прекратит пользоваться сервисом.

В данном проекте основной акцент сделан не только на построении модели,
но и на **инженерных аспектах масштабирования ML‑пайплайна**.

Проект показывает, как один и тот же workflow может быть реализован в
трёх вариантах:

  -----------------------------------------------------------------------
  Версия                  Инфраструктура          Назначение
  ----------------------- ----------------------- -----------------------
  Local                   Один компьютер          Базовый ML pipeline

  Dask Local Cluster      Локальный               Параллельная обработка
                          распределённый кластер  

  Dask + Kubernetes       Кластер Kubernetes      Масштабируемая
                                                  cloud‑инфраструктура
  -----------------------------------------------------------------------

Таким образом демонстрируется эволюция ML‑проекта:

    локальный прототип → распределённый pipeline → cloud‑ready ML система

------------------------------------------------------------------------

# Архитектура

## 1. Локальный ML Pipeline

Классический workflow машинного обучения на одном компьютере.

    Dataset
       ↓
    Предобработка данных (Pandas)
       ↓
    Feature Engineering
       ↓
    Обучение модели (Scikit‑learn)
       ↓
    Оценка модели

Используется для:

-   быстрого прототипирования
-   анализа данных
-   построения baseline модели

------------------------------------------------------------------------

## 2. Distributed Pipeline (Dask Local Cluster)

Используется **Dask**, который позволяет параллелизовать обработку
данных.

    Dataset
       ↓
    Dask DataFrame
       ↓
    Параллельная предобработка
       ↓
    Distributed feature engineering
       ↓
    Обучение модели

Преимущества:

-   ускорение обработки данных
-   масштабирование вычислений
-   распределённое использование памяти

------------------------------------------------------------------------

## 3. Distributed Pipeline (Dask + Kubernetes)

В этом варианте Dask разворачивается внутри **Kubernetes‑кластера**.

    Dataset
       ↓
    Dask Cluster (Kubernetes)
       ↓
    Distributed processing
       ↓
    Training
       ↓
    Evaluation

Этот вариант демонстрирует:

-   горизонтальное масштабирование
-   оркестрацию вычислений
-   cloud‑ready ML pipeline

# Данные

Проект использует датасет с информацией о поведении клиентов.

Типичные признаки:

-   демография клиента
-   информация об аккаунте
-   использование сервиса
-   история подписки
-   платежные данные

Целевая переменная:

    churn = 1  → клиент ушёл
    churn = 0  → клиент остался

Задача формулируется как **binary classification**.

------------------------------------------------------------------------

# ML Pipeline

Пайплайн машинного обучения состоит из следующих этапов.

## 1. Загрузка данных

Чтение и подготовка исходного датасета.

## 2. Предобработка

-   обработка пропущенных значений
-   кодирование категориальных признаков
-   очистка данных

## 3. Feature Engineering

-   генерация новых признаков
-   нормализация
-   подготовка признакового пространства

## 4. Train/Test Split

Данные разделяются на:

    train
    validation
    test

## 5. Обучение модели

Используемые алгоритмы:

-   Logistic Regression
-   Random Forest
-   Gradient Boosting

## 6. Оценка модели

Метрики:

-   Accuracy
-   Precision
-   Recall
-   F1‑score
-   ROC‑AUC

# Установка

Клонирование репозитория:

    git clone https://github.com/Skerter/distributed-churn-prediction.git
    cd distributed-churn-prediction

Создание виртуального окружения:

    python -m venv venv
    source venv/bin/activate

Установка зависимостей:

    pip install -r requirements.txt

------------------------------------------------------------------------

# Запуск экспериментов

## Локальный pipeline

Откройте notebook:

    notebooks/local_pipeline.ipynb

------------------------------------------------------------------------

## Dask локальный кластер

Запустите кластер:

    dask scheduler
    dask worker

После этого откройте:

    notebooks/dask_local_cluster.ipynb

------------------------------------------------------------------------

## Dask Kubernetes

Разверните Dask cluster внутри Kubernetes и выполните:

    notebooks/dask_kubernetes_cluster.ipynb
